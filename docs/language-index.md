## Operators Quick Reference

### Arithmetic
- `+` - Addition
- `-` - Subtraction
- `*` - Multiplication
- `/` - Division
- `%` - Modulo

### Assignment
- `=` - Basic assignment
- `+=`, `-=`, `*=`, `/=`, `%=` - Compound assignment
- `??=` - Nullish assignment

### Comparison
- `==`, `!=` - Equality
- `===`, `!==` - Strict equality
- `<`, `>`, `<=`, `>=` - Relational

### Logical
- `&&` - Logical AND
- `||` - Logical OR
- `!` - Logical NOT
- `??` - Nullish coalescing

### Special
- `=>` - Arrow function
- `|>` - Pipeline operator
- `?` - Ternary conditional
- `.` - Member access
- `::` - Type annotation
- `@` - Decorator
- `++`, `--` - Increment/decrement
